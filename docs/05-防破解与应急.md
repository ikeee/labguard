# 防破解与应急（学生停服务 / 删目录 怎么办）

> 一句话结论：**软件只能自动挡到"标准账户"这一层**；学生如果是本地管理员，任何用户态程序都拦不住他（Windows 的安全模型如此，原版也一样）。
> 所以正确做法是三层叠加：**① 软件自动恢复（已内置）② 部署层收权限 + 无盘还原 ③ 可见性与问责（心跳监视器 + 日志）**。

---

## 1. 攻击 → 现在的行为（软件已内置的部分）

| 学生的动作 | 现在会发生什么 | 还需你做什么 |
|---|---|---|
| 任务管理器结束"小助手"进程 | 小助手以**最高权限**运行 → 标准用户根本杀不掉（拒绝访问）；就算杀掉，服务 10 秒内重新拉起 | 无 |
| `net stop LabGuardSvc` / `sc stop` | 服务 DACL 已**去掉"停止"权限**（普通用户只剩 查询/启动）→ 直接拒绝。异常终止则 **5 秒内自动重启**（`sc failureflag 1` + `restart/5000`） | 无 |
| 把服务删掉（`sc delete`） | 需要管理员权限；普通用户拒绝。真删了 → 开机计划任务会再拉起小助手，小助手发现服务不存在会在日志/托盘告警 | 无（若学生是管理员，见第 3 节） |
| **删除程序目录 / 删文件** | ① 目录 ACL = 普通用户只读，删不了；② 真的被删 → 服务每 10 秒体检，从**系统级备份副本** `%ProgramData%\LabGuard\payload`（只有 SYSTEM/管理员能访问）**自动恢复**；也可手工 `payload\LabGuard.Service.exe --restore-files <安装目录>` | 无 |
| 停服务后再删目录（"组合拳"） | 服务镜像本身就放在 `payload` 目录里运行 → 删安装目录不影响服务存活，服务随后把安装目录整棵树恢复回来 | 无 |
| **删除/破坏配置文件**（想变成"未配置 = 不监控"） | 配置在注册表里有 DPAPI 加密镜像（`HKLM\SOFTWARE\LabGuard\CfgData`），发现 config.json 缺失会**自动恢复**并在日志/`--show-config` 里标注"配置来源：从注册表备份恢复"；该注册表键已被加固，普通用户改不了 | 无 |
| 免密改密码 / 免密卸载 | 改密码必须提供旧密码（`--old`）；卸载要密码；静默卸载必须 `--password`；只有老师显式 `--force` 才免密 | 无 |
| 用"带网络的安全模式"绕过 | 该模式已被移除（`SafeBoot\Network` 删除前会导出备份）；**安全模式（含无网络）里我们不加载任何管控**——这条刻意留着当老师的后路 | 无（见第 4 节） |
| 拔电源 / 长按电源键 | 策略写在注册表里，重启后仍生效（登录后立即重新下发）——但这段过程里他确实自由了几十秒 | **无盘还原/还原卡**：重启即回到你的母盘状态 |
| U 盘启动 PE、离线改注册表/删文件 | **软件无解**（操作系统都没起来） | BIOS 里禁 USB 启动、机箱加锁、无盘启动 |
| 想"神不知鬼不觉" | 每 60 秒把本机状态（机位/用户/服务状态/是否暂停/DNS/是否疑似被破坏）上报给教师机监视器；超过 3 分钟没上报就是红的 | 见第 3 节：起一个监视器 |

## 2. 学生是本地管理员？（最关键的一节）

如果学生账号有**管理员**权限，那么上表里所有"拒绝访问"都会失效——他可以：
改服务 DACL（`sc sdchange`/`sc config`）、删 `payload` 目录、改注册表、改配置文件、删计划任务。

**这不是本程序（或任何同类程序）能解决的问题。** 原版《学生机房管理助手》的做法是"删文件就蓝屏锁定、服务异常就重启电脑"——用**恐吓**换时间，
代价是：误伤正在做作业/考试的学生，而且照样挡不住管理员（他可以直接断电源）。

所以按性价比，我建议你这样收口：

1. **把学生账户降为标准用户**（最有效的一招）。需要装软件的课，用"老师密码暂停监控"或临时提权的方式；
2. **无盘 / 云课室 / 还原卡**：学生改了什么，重启就回来（这条对"删目录、停服务"几乎是终极解）；
3. **BIOS 禁 USB 启动 + 机箱锁**：挡住 PE 离线改；
4. **教师端监视器**（见下）：让"停服务/删目录"变成看得见的行为，配合机房管理制度做问责——现实里这一条往往比技术对抗有效；
5. 交换机层只让 53 端口到教师机（配合集中 DNS），切断"换条路上网"。

## 3. 可选：教师端监视器（看得到 = 管得住）

1. 在**教师机**上运行（管理员 PowerShell 一次即可）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File monitor-receiver.ps1 -Port 8080
   ```
   它会打印学生机要填的地址，例如 `http://192.168.1.10:8080/heartbeat`。
   若提示绑定失败，先执行一次：`netsh http add urlacl url=http://+:8080/ user=Everyone`
2. 在学生机【设置】→ 第 13 组 → **心跳上报地址**填上面那个 URL（或安装时用预设/`--config` 下发）。
3. 浏览器打开 `http://<教师机IP>:8080/` → 表格实时刷新：
   - 绿色 = 正常；橙色 = 服务没在跑 / 疑似被破坏；**红色 = 超过 3 分钟没上报（被停了、被删了、或者机器关机）**

## 4. 留的后路：安全模式不加载 + 一键彻底卸载

**设计取舍**：安全模式**不加载**我们的服务/小助手（默认如此）。原因很简单——万一程序出问题、密码忘了、或者学校不再使用，
老师必须有一条**一定能进去**的路。代价是学生理论上也能用安全模式"暂时不受管控"，但：
① 我们删掉了"带网络的安全模式"，他在安全模式里上不了网；
② 真要玩这一手，监视器会看到这台机器**掉线**（红），老师一眼就知道。

| 后路 | 怎么做 |
|---|---|
| **① 安全模式（无网络）** | 开机按 F8 / `msconfig` → 安全启动 → 进系统后我们的服务与小助手**不会加载**，随你处理 |
| **② 一键彻底卸载脚本**（不需要安装目录里的任何文件） | 管理员 PowerShell：`powershell -ExecutionPolicy Bypass -File cleanup-all.ps1`（先确认；`-Force` 免确认；`-DryRun` 只打印；`-KeepFiles` 保留程序目录）。**安全模式下也能跑** |
| ③ 卸载程序（常规） | `LabGuard.Uninstall.exe`（要密码）或 `uninstall.ps1 -ForceReset`（忘记密码时） |
| ④ 手工 | 删服务 `sc delete LabGuardSvc`、删计划任务 `schtasks /delete /tn LabGuard\Agent /f`、删 `HKLM\SOFTWARE\LabGuard`、删程序目录（默认 `C:\f<内存指纹>`） |

`cleanup-all.ps1` 会做 18 步（实测通过）：停/删服务 → 结束进程 → 删计划任务与安全模式登记 → 还原 hosts（含备份）→
恢复 U 盘 → 清浏览器组策略/IFEO/任务栏策略/壁纸 → 还原"带网络的安全模式"（有备份时）→ 恢复启动菜单默认值 →
删快捷方式/注册表/程序目录/系统级备份副本 → 保留日志（`-KeepLogs:$false` 可连日志一起删）。

> 如果你**就是要**"安全模式也得受管控"（不推荐），可在设置第 10 组打开「安全模式下也继续管控」——
> 但那等于把老师自己的后路也堵上，建议至少保留 `cleanup-all.ps1` 和安装包在教师机/U 盘上。

## 5. 已有的加固入口（可重复执行）

```powershell
# 给已安装的机器做抗破解加固（服务权限 + 自动重启 + 安全模式服务 + 系统级备份副本）
powershell -ExecutionPolicy Bypass -File harden-service.ps1

# 手工触发文件自愈（把被删/被改的文件从备份副本恢复）
"C:\ProgramData\LabGuard\payload\LabGuard.Service.exe" --restore-files "C:\f<内存指纹>"

# 逐台核对当前策略（含"配置是否被恢复过"）
LabGuard.Settings.exe --show-config
```

## 6. 忘记密码怎么办（老师侧）

| 情况 | 做法 |
|---|---|
| 只是忘了密码，想改 | 需要旧密码才能改。真忘了 → 用下面的强制卸载，再重新安装并设新密码 |
| 强制卸载（不需要密码） | 管理员运行 `LabGuard.Uninstall.exe --force`（或 `uninstall.ps1 -ForceReset`）→ 会逐项还原系统 |
| 想保留策略只重置密码 | 管理员运行 `LabGuard.Settings.exe --init <新密码>`，本机已设密码时要加 `--old <旧密码>`；连旧密码也不知道 → 只能强制卸载重装 |
| 程序文件被杀毒软件误删 | 服务会自动恢复；也可手工 `--restore-files` |

> 记住：**"忘记密码也能救"和"学生拿不到后门"天生矛盾**。所以救援命令只写在老师自己的介质上（`dist\`、`docs\`），
> 一键安装程序**不会**把它们装到学生机的安装目录里。
