# 教师解锁通道设计

> 状态：已实现；具体组合只进入私有发布构建，不进入公开仓库、文档、界面或日志。

## 目标

- 断网遮罩必须保留一个管理员出口，避免整排机器因网络配置问题无法恢复。
- 学生不应从屏幕、设置界面、日志或公开文档中得知通道细节。
- 合成键盘输入、自动重复、左右修饰键混用和小键盘方向键不得推进状态。

## 设计要点

1. 状态机不依赖 WinForms，可单独自检。
2. 管理员先按住同一侧的一组修饰键，全部松开后进入短时间窗口；窗口内输入私有方向序列。
3. 旧版公开组合完全失效，不再由配置项或默认值提供。
4. 连续错误达到上限后关闭本次遮罩的私有通道；界面不提示通道是否存在。
5. 密码通道继续可用；遮罩关闭时统一停止计时器、网络监听和键盘钩子。

私有构建通过 `Assets/private-unlock.profile` 注入实际资料；该文件被 `.gitignore` 排除，不随公开源码提交。
