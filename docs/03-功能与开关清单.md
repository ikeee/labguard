# 功能与开关清单

> 每个功能都对应设置程序里的一个开关（共 **94 项 / 14 组**），并且由自检强制"无隐藏开关"：
> `LabGuard.SelfTest.exe` 的 `[7] 设置项覆盖` 会反射核对"配置项集合 == 界面开关集合"，并做读写往返校验。

## 1. 功能总览

| 能力 | 实现方式 | 默认 |
|---|---|---|
| 保护课堂软件（极域 / 红蜘蛛 / 锐捷云课堂）进程存活 | 轮询进程状态；被挂起 → 强制恢复；被结束 → 重新拉起 | 开 |
| 保护课堂软件关键服务 | 检测服务是否运行，停就启动 | 开 |
| 课堂软件参数守护 | 监控其频道/自动登录参数，被改回写合法值 | 开 |
| 拔网线 / 禁用网卡检测 | 网卡 Down / IP 空 / `0.0.0.0` / `169.254.*`，**持续 20 秒**确认（开机 120 秒预热） | 开（只提示） |
| 断网全屏遮罩 | 全屏置顶 + 吞键 + 随机壁纸背景 + 机位号 + 已断开时长；**恢复网络 10 秒内自动消失**；老师 5×Esc + 密码解除 | 开 |
| 断网响鸣 | 满 N 秒后响 M 次（次数上限可配，避免扰民） | 开（60 秒后 3 次） |
| 改 IP 还原 | 与启动基线比对，用 `netsh` 还原（DHCP 的机器改回 DHCP） | 开 |
| 防火墙自愈 | 检测"阻止所有传入连接"被开启 → 关闭 | 开 |
| 违规软件拦截 | 进程名 + 窗口标题双表（破解工具 / 进程工具 / 虚拟桌面 / 杀软 / 解压 / 小游戏 / 系统工具） | 开（结束进程） |
| 小游戏与系统命令禁用 | IFEO（Image File Execution Options）把目标程序 `Debugger` 指空 | 开 |
| 新文件/下载监控 | FileSystemWatcher + 扩展名三档策略（全部允许 / 仅 C++ / 全部禁止） | 开（仅 C++） |
| USB 存储设备控制 | `usbstor` 驱动 `Start=4`（键鼠保留），退出还原 | 开（禁止） |
| hosts 域名黑名单 | 写入受管区块 + 隐藏 + 只读守候；被删/被改自动恢复 | **关**（可选） |
| hosts 文件保护 | ACL 收紧为普通用户只读 + 内容基线守候（防本地写映射） | 开 |
| 浏览器策略 | 组策略：禁下载/另存为/开发者工具、关小恐龙与 Edge 冲浪、关加密 DNS（DoH） | 开 |
| 集中 DNS 锁定 | 每 15 秒核对 DNS，被改即改回 + `flushdns`；带 DNS 服务器存活探针 | **关**（可选，需填服务器地址） |
| 网卡判据（一体机/热点机房） | 只监视有线网卡；忽略 Wi-Fi Direct / 移动热点 / 虚拟网卡；遮罩恢复条件只看判据网卡 | 开 |
| 任务栏与系统工具策略 | 隐藏任务视图、禁任务栏右键、禁任务管理器/注册表编辑器/cmd/锁定工作站、隐藏扩展名 | 开 |
| 安全模式限制 | 删除 `SafeBoot\Network`（带网络的安全模式），删除前导出备份 | 开 |
| 桌面壁纸与机位编号 | 6 张自绘规范壁纸 + 右上角显示计算机名后 6 位，被改自动恢复 | 开 |
| 注册表权限加固 | 配置键"普通用户只读、管理员/SYSTEM 完全控制" | 开 |
| 自我保护 | 服务不能被普通用户停止、异常 5 秒自动重启、服务镜像放受保护目录、程序文件被删/被改自动恢复、配置有注册表加密镜像 | 开 |
| 心跳上报 | 每 60 秒把状态 POST 给教师端监视器（可选） | 关（留空地址即不上报） |
| 口令保护 | 退出/暂停/改设置/解除遮罩/卸载全部要密码；改密码需旧密码 | — |
| 老师后路 | 安全模式（含无网络）**不加载**任何管控；`scripts/cleanup-all.ps1` 一键彻底卸载还原 | — |

## 2. 三档上网管控（可选）

| 档位 | 需要什么 | 开关位置 |
|---|---|---|
| A 不控（默认） | 什么都不需要 | 第 3 组不勾、第 7 组不勾 |
| B 本地 hosts 黑名单 | 什么都不需要 | 第 7 组「启用 hosts 域名黑名单」 |
| C 集中 DNS | 教师机/内网服务器的 DNS 过滤服务（如 AdGuard Home） | 第 3 组：填地址 + 勾「锁定学生机 DNS」+ 勾「关闭 DoH」 |

## 3. 配置组一览（设置程序）

| 组 | 内容 |
|---|---|
| 0 总体 | 总开关、开机延迟、暂停后自动恢复 |
| 1 课堂软件保护 | 总开关、学生端路径/进程名/服务名、挂起恢复、被结束拉起、参数守护 |
| 2 网络与防火墙 | 总开关、断网检测、遮罩（背景/时长）、响鸣（起始/次数/间隔）、改 IP 还原、防火墙自愈、网卡判据、违规时锁屏/关机 |
| 3 集中 DNS | 总开关、DNS 地址、关闭 DoH、只锁判据网卡 |
| 4 违规软件拦截 | 总开关 + 8 类清单开关、处置动作、额外关键词 |
| 5 新文件监控 | 总开关、三档强度、动作、监控目录、高危扩展名、放行扩展名 |
| 6 USB | 总开关、允许/禁止存储设备、保留键鼠外设 |
| 7 hosts 黑名单 | 总开关、只读保护、守护、隐藏、内置清单、屏蔽地址、额外域名 |
| 8 浏览器 | 总开关 + 6 个策略开关、主页、快捷方式接管 |
| 9 任务栏与系统工具 | 总开关 + 9 个策略开关 |
| 10 安全模式与启动菜单 | 总开关、安全模式下是否运行、禁带网络的安全模式、隐藏启动菜单 |
| 11 桌面壁纸与编号 | 总开关、图片、显示编号、取几位、被改自动恢复 |
| 12 注册表权限加固 | 总开关、加固键列表 |
| 13 互相守护与自我保护 | 总开关、文件自愈、心跳上报地址、代理拉起间隔、服务异常重启电脑、文件被改锁定 |
| — 密码 | 单独一组（PBKDF2-SHA256 保存） |

## 4. 系统改动清单（便于审计与还原）

| 位置 | 用途 |
|---|---|
| `HKLM\SOFTWARE\LabGuard`（含加密配置镜像 `CfgData`） | 安装标记 + 配置备份 |
| `%ProgramData%\LabGuard\`（`config.json` / `logs\` / `payload\` / `files.sha256`） | 配置（DPAPI 加密）、日志、系统级备份副本、完整性清单 |
| `SYSTEM\CurrentControlSet\Services\usbstor`（+ControlSet001~003） | USB 存储禁用/还原 |
| `...\Image File Execution Options\<游戏/命令>` | 禁用指定程序 |
| `SOFTWARE\Policies\Google\Chrome` / `Microsoft\Edge` / `Mozilla\Firefox` / `...\Internet Explorer\Restrictions` / `...\DNSClient\DoHPolicy` | 浏览器与加密 DNS 策略 |
| `HKCU\...\Explorer\Advanced`、`HKCU\...\Policies\{System,Explorer}` | 任务栏/系统工具/文件夹选项 |
| `HKCU\Control Panel\Desktop` | 壁纸 |
| `SYSTEM\CurrentControlSet\Control\SafeBoot\Network` | 禁止"带网络的安全模式"（有备份可还原） |
| hosts 文件（受管区块，可选）+ ACL 只读 | 域名黑名单（可选）与本地防篡改 |
| 服务 `LabGuardSvc`、计划任务 `LabGuard\Agent`、快捷方式、控制面板卸载项 | 自启动与卸载 |
| 各网卡 DNS（`netsh`，可选） | 集中 DNS 锁定 |

一键还原：卸载程序（要密码）或 `scripts/cleanup-all.ps1`（不需要安装目录里的文件，安全模式可用）。
