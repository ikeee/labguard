# 复刻版设计说明

## 1. 技术选型（与原版对齐）

| 项 | 选择 | 理由 |
|---|---|---|
| 语言/框架 | C# + .NET Framework 4.8（`net48`） | 原版是 .NET 4.5 + WinForms；4.8 是 Win7 SP1/10/11 自带的最后一代 .NET Framework，学生机**零安装依赖** |
| UI | WinForms（纯代码构建，无设计器） | 与原版一致；纯代码便于版本管理 |
| 进程模型 | 1 个服务（SYSTEM） + 1 个托盘代理（用户会话） + 设置/卸载/上网入口 | 对应原版 zmserv + about/jfglzsn/przs + set/uninstall/zy |
| 配置 | `%ProgramData%\LabGuard\config.json`（DPAPI LocalMachine 加密）+ `HKLM\SOFTWARE\LabGuard` 最小镜像 | 原版把所有开关塞在 `HKLM\Software\jfglzs`（值名混淆）；复刻版用加密 JSON，可读可审计 |
| 口令 | PBKDF2-SHA256（盐 16B、10 万次迭代、32B 输出，`pbkdf2-sha256$迭代$盐$散列`） | 原版用 CAPI 哈希 + 明文默认口令 `111111`；复刻版必须更安全 |
| 构建 | `dotnet build` + `Microsoft.NETFramework.ReferenceAssemblies` | 无需安装 Visual Studio / .NET Framework 开发者包 |
| 部署 | `scripts/install.ps1`（sc create + schtasks + 快捷方式 + ACL + 壁纸生成） | 原版 Advanced Installer MSI；脚本更透明、可审计、可参数化 |

## 2. 分层

```
LabGuard.Settings / LabGuard.Uninstall / LabGuard.Agent
                    │
                    ▼
              GuardEngine（装配 + 违规动作分发 + 暂停/退出）
                    │
        ┌───────────┴────────────┐
```

### 2.1 Guard 清单

| 角色 | Guard | 职责 |
|---|---|---|
| Full（用户会话） | `NetworkGuard` | IP 基线、断网（网卡 Down／IP 空／`0.0.0.0`／`169.254.*`，20 秒去抖）、防火墙自愈 |
| Full | `DnsGuard` | 集中 DNS 锁定（DNS 被改即 `netsh` 改回）+ AdGuard 存活探针 |
| Full | `ClassroomGuard` | 电子教室进程存活/挂起/服务/极域参数 |
| Full | `ProcessBlockGuard` | 违规软件双表拦截 + IFEO 映像劫持 |
| Full | `ShellPolicyGuard` | 任务视图/任务栏右键/任务管理器/注册表/cmd/文件扩展名 |
| Full | `KeyboardHookGuard` | 低级键盘钩子吞掉 Win 键（需消息循环，故放代理进程） |
| Full | `WallpaperGuard` | 生成带机器编号的壁纸并守护 |
| Full / SystemCore | `WatchdogGuard` | 服务与代理互相拉起、关键文件 SHA256 校验、暂停标记 |
| SystemCore（服务） | `HostsGuard` | **默认只保护 hosts**：ACL 收紧为普通用户只读 + 内容基线守候（被写映射即还原）；`Hosts.Enabled=true` 时才写黑名单区块并守护 |
| SystemCore | `UsbGuard` | `usbstor` Start=4 / 还原 3 |

| SystemCore | `FileCreationGuard` | `FileSystemWatcher` 新文件三档策略 |

### 2.2 关键设计点

0. **"每个功能都有开关"是硬约束**：`LabGuard.Core/Settings/SettingsCatalog.cs` 用一张**声明式配置目录**描述全部
   80 个开关（含 `Path` 字符串、Getter/Setter、取值范围、危险标记），设置界面由目录渲染。
   `SelfTest` 用反射核对"配置属性集合 == 目录集合"并做 Get/Set 往返校验，
   因此**新增配置项却忘了做界面**会在自检里直接失败（不会悄悄藏在代码里）。
   另提供 `ConfigStore.Serialize/Deserialize/ExportTo/ImportFrom` 支持配置导出导入（含口令散列，可整机房复制）。

1. **所有系统写操作走 `SystemActions`**：每个写操作先落审计（`AuditTrail`），`Log.DryRun` 为真时只记录不执行。
   这样"干跑自检"能完整验证判定逻辑与装配，而完全不碰系统（已用系统状态快照实测）。
2. **每个 Guard 都有 `OnStop()` 还原分支**，且能"不启动只还原"（`AttachContext` + `Stop`），
   卸载与"退出程序"走 `GuardEngine.RestoreEverything` 一次性还原。
3. **暂停机制**：密码暂停 → 写 `%ProgramData%\LabGuard\paused.flag` → 停止引擎 → 服务侧 `WatchdogGuard` 看到标记就不再拉起代理，避免"老师退出、学生机器被反复重启"。
3b. **网络判据（`NicRoles`）**：断网/改 IP/DNS 锁定都只作用在"判据网卡"上——
   优先取设置里显式指定的网卡，其次自动取"有默认网关"的网卡，并排除 Wi-Fi Direct / 移动热点（`192.168.137.1`）/ Hyper-V / VMware / 蓝牙等虚拟或热点网卡。
   这样"有线为主 + 无线常开做热点"的一体机机房不会出现"热点一关就误报拔网线""热点还开着就让遮罩误判网络已恢复"这两类错误。
4. **误判防线**：开机默认 120 秒（`StartDelaySeconds`）后才开始网络/进程判定（原版经验值）；违规提示同一文案 5 秒去重，避免轮询刷屏。
5. **锁定屏**：`LockScreenForm` 全屏置顶 + 键盘钩子（吞 Win/Alt+Tab/Alt+Esc/Ctrl+Esc）+ 密码解锁 + 条件自愈自动解锁。

## 3. 注册表 / 文件改动清单（便于审计与还原）

| 位置 | 目的 |
|---|---|
| `HKLM\SOFTWARE\LabGuard`（Installed/Enabled/Version/InstallDir） | 安装标记 + 配置镜像；**加固：拒绝 Builtin\Users 写入** |
| `%ProgramData%\LabGuard\config.json`、`logs\`、`files.sha256`、`wallpaper-active.jpg`、`safeboot-network.reg`、`paused.flag` | 配置/日志/完整性清单/生成壁纸/安全模式备份/暂停标记 |
| `SYSTEM\CurrentControlSet\Services\usbstor`（+ControlSet001~003） | USB 存储禁用/还原 |
| `SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\<游戏/命令>` | 直接禁用小游戏与 taskkill/ntsd/tasklist/route |
| `SOFTWARE\Policies\Google\Chrome` / `Microsoft\Edge` / `Mozilla\Firefox` / `Microsoft\Internet Explorer\Restrictions` | 浏览器下载/游戏/开发者工具策略 |
| `HKCU\...\Explorer\Advanced`（ShowTaskViewButton/HideFileExt/NoFolderOptions） | 任务视图、文件夹选项 |
| `HKCU\...\Policies\System`（DisableTaskMgr/DisableRegistryTools/DisableLockWorkstation） | 系统工具限制 |
| `HKCU\...\Policies\Explorer`（NoTrayContextMenu） | 任务栏右键 |
| `HKCU\Control Panel\Desktop`（Wallpaper/WallpaperStyle） | 壁纸 |
| `SOFTWARE\Policies\Google\Chrome`、`Microsoft\Edge` 的 `DnsOverHttpsMode`/`BuiltInDnsClientEnabled`、`Mozilla\Firefox\DNSOverHTTPS`、`Microsoft\Windows NT\DNSClient\DoHPolicy` | 关闭加密 DNS（DoH），保证集中 DNS 过滤有效 |
| `SYSTEM\CurrentControlSet\Control\SafeBoot\Network` | 禁止带网络的安全模式（有备份） |
| `%SystemRoot%\System32\drivers\etc\hosts`：**ACL 收紧为"管理员/SYSTEM 可写、普通用户只读"**；`Hosts.Enabled=true` 时另有受管区块 + `hosts.labguard-bak` 备份 | 防本地 hosts 绕过 / 可选黑名单 |
| 各网卡的 DNS 服务器（`netsh interface ip set dns`） | 锁定指向教师机 AdGuard 的集中 DNS |
| 服务 `LabGuardSvc`、计划任务 `LabGuard\Agent`、快捷方式、`Uninstall\LabGuardReplica` | 自启动与卸载登记 |

## 4. 已知取舍 / 待办

- 未实现原版的"断网 2 分钟后全屏锁定"的**强制**策略（默认只提示 + 自动恢复；断网检测用"持续 20 秒"去抖，避免交换机抖动/无盘启动慢导致整排机器被误锁），可在 `NetworkSettings` 打开 `LockOnViolation` / `ShutdownOnViolation`。
- **上网管控主防线改为集中 DNS**（有教师机 AdGuard 的场景）：`Network.DnsServers` 填教师机 IP 后，`DnsGuard` 保证学生改不掉；`Hosts.Enabled` 默认 `false`。代价是**教师机成为单点**：AdGuard 不起，学生机域名解析全失效（表现为"没网"），所以 AdGuard 必须开机自启、教师机自己做受管终端。
- DNS 锁定采用"强制静态"策略（`netsh … static`）：配置文件留空即完全不锁定（适合校园 DHCP 统一下发 DNS 的场景）。
- **断网遮罩的取舍**：不做"按任何键都不能退出"的硬锁定——① 用户态程序挡不住 Ctrl+Alt+Del→注销/任务管理器，硬扛只会变成"打地鼠"；② 考试/教学软件本身可能全屏置顶，双全屏叠加会让学生以为机器死机；③ 没有逃生出口的锁屏在出故障时会把整排机器卡死（原版蓝屏锁定的老毛病）。所以实现为：**吞键 + 插回网线自愈 + 老师 5×Esc/密码出口**；响鸣做**次数上限**（默认 3 次）而不是长鸣，避免成为新的课堂干扰手段。
- 未实现原版的 `.dat` 状态文件与"进程被多次终止"计数提示（改为 SHA256 完整性清单）。
- 新文件监控默认只监控根目录 + 用户下载目录（非递归到全盘），如需更严格可调 `FileCreation.WatchPaths`。
- 浏览器快捷方式接管是"按要求启动浏览器"，不修改系统默认浏览器关联。
- 未做静默批量部署（可加 `install.ps1 -SimplePath -InstallDir` + 组策略下发）。
