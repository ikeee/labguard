# 机房部署指南（LabGuard·）

> 目标：把 `dist\` 装到机房的学生机/一体机上，并让两个机房各自用对策略。
> 原则：**先 1 台试跑 → 再整机房**；**每台机器都能一键还原**；**不要求卸载杀毒、不改 UAC 设置**（这是与最大的不同）。

---

## 0. 前置条件（5 分钟检查）

| 项 | 要求 | 怎么确认 |
|---|---|---|
| 权限 | 每台机器**管理员**权限 | 用「管理员 PowerShell」运行 |
| 系统 | Win10 / Win11（自带 .NET Framework 4.8）；Win7 SP1 需先装 .NET Framework 4.8/4.7.2 | `reg query "HKLM\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full" /v Release` |
| 杀毒软件 | **不需要卸载**；但要把安装目录加入白名单（否则可能误删程序文件） | 360/火绒/Defender 的「信任区/排除项」加目录 |
| 硬盘保护/还原卡 | 装完再保存进度，否则重启还原 | 电子教室/云课室自带的保护系统 |
| 网络 | **可选**：只有要用"集中 DNS（第 C 档）"时才需要学生机能访问教师机的 AdGuard；不用 AdGuard 就不需要这一项 | 学生机上 `nslookup www.baidu.com <教师机IP>` |
| 交付物 | `dist\` 整个目录（5 个 exe + `LabGuard.Core.dll` + `wallpaper\` + 脚本 + 文档） | 见 `release\*.zip` |

**UAC 不需要改成"从不通知"**：小助手由"最高权限计划任务"在登录时拉起，设置/卸载程序自带要求管理员权限的清单（会弹一次 UAC）。

## 1. 拿到安装包

**首选：一键安装程序（单文件 exe）**

1. 从 [Releases](https://github.com/ikeee/labguard/releases) 下载 **`LabGuard-Setup-v0.01.exe`**（或完整包 `labguard-v0.01.zip`）；
2. 拷到学生机（U 盘/内网共享/文件服务都行）→ **双击** → 向导：合规确认 → 安装位置 → **课堂软件（自动识别/手动填写）** → 密码 → **功能开关（92 项，可搜索/只看已改动）** → 安装；见 `README.md` 第 2 节；
3. 内网自取也可以：把 exe 放到共享（如 `\\fileserver\share\`），学生机双击运行即可。

其它来源（按需）：完整包 `labguard-v0.01.zip` 里的 `dist\` 是"脚本部署版"；从源码构建用 `scripts\build.ps1 -SelfTest` + `scripts\build-installer.ps1`。

> **AdGuard / 上网管控是可选项**：默认（什么都不勾）= 不做域名过滤，程序照样完整工作；
> 需要更强过滤时再选「本地 hosts 黑名单」或「集中 DNS（教师机 AdGuard）」。详见 README 第 1.5 节。

> ⚠️ **顺序很重要**：现在这个程序会**禁用 U 盘**（第 6 组默认禁止存储设备）。所以**先把安装包拷进机器，再安装**；装好后想用 U 盘，请用密码暂停或退出小助手。

## 2. 部署路径（按机房的实际情况挑一种）

### 方案 A：逐台手动（最稳，适合 ≤20 台 / 首次试运行）

```powershell
# 1) 把 dist 拷到学生机（例如 D:\lg\），在该目录里：
#    右键 install-as-admin.cmd → 以管理员身份运行（或右键 PowerShell 用管理员打开后执行下一行）
powershell -ExecutionPolicy Bypass -File install.ps1

# 2) 打开桌面/开始菜单里的【设置】，设密码、逐项确认策略，保存
# 3) 在硬盘保护/还原系统里"创建进度 / 保存系统"
```

### 方案 A2：无人值守（一行命令装完，适合批量）

**用一键安装程序**（推荐）：

```powershell
# 管理员 PowerShell
LabGuard-Setup-v0.01.exe --silent --password "你的密码123" --config "presets\主机房-普通PC.json" --dns "192.168.1.10"
#   --dns 只在要用"集中 DNS（AdGuard）"时才需要；不用 AdGuard 就不要这个参数（= 不做域名过滤）
#   --classroom "C:\...\StudentMain.exe" 指定课堂软件学生端（不给就自动识别，识别不到可在设置里填）
#   --no-start 装好但先不启用；--dry-run 只打印步骤不改系统
```

**用脚本**（在 `dist\` 目录里）：

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 `
  -ConfigJson "presets\主机房-普通PC.json" `
  -Password "你的密码123" `
  -Dns "192.168.1.10"        # 可选：仅在用集中 DNS(AdGuard) 时填
```

- `-Password`：直接设好小助手密码（不设的话装完必须手动跑设置程序，未设密码前**监控不启用**）
- `-ConfigJson`：套用预设（见第 3 节）
- `-Dns`：集中 DNS（教师机 IP，可逗号分隔多个）
- `-InstallDir`：指定安装目录（默认 `C:\Program Files\LabGuard`）
- `-DryRun`：**只打印将要做的步骤，不改系统**（上课前预演、或者你想先看清楚它做什么）

核对结果（会把报告同时写到 `%ProgramData%\LabGuard\logs\deploy-show-config-*.log`）：

```powershell
dist\LabGuard.Settings.exe --show-config
dist\LabGuard.SelfTest.exe            # 全绿才算装好
```

### 方案 C：母盘 / 无盘 / 云课室（最快，推荐给有电子教室派发能力的机房）

1. 在**母盘（模板机）**上按方案 A 或 B 装好并配好；
2. 先做一次验收（第 5 节清单）；
3. 用电子教室/云课堂/无盘系统把母盘**保存镜像并派发**到全班。

> 注意：派发后每台机器的机器名不同 → 壁纸上的"机位编号"是运行时按计算机名后 6 位生成的，**无需逐台改**。
> 如果母盘的计算机名也没改，请先在母盘把命名规则定好再派发。

### 方案 D：域环境 / 有远程执行工具

- 把 `install.ps1` 作为**计算机启动脚本**（GPO）或登录脚本下发（需保证幂等，本脚本可重复执行）；
- 或用 PsExec/WinRM 批量：
  ```powershell
  # 需要目标机可访问 + 有管理员凭据
  PsExec.exe @machines.txt -s -d powershell -ExecutionPolicy Bypass -File \\server\share\dist\install.ps1 -Password xxx -ConfigJson \\server\share\dist\presets\主机房-普通PC.json -Dns 192.168.1.10
  ```

## 3. 两个机房各自的配法

预设文件在 `presets\`，可直接 `-ConfigJson` 使用，也可在设置程序里【导入配置】。

| 项 | 主机房（普通 PC） | 一体机机房（有线为主 + 无线常开做热点） |
|---|---|---|
| 预设文件 | `presets\主机房-普通PC.json` | `presets\一体机机房-有线为主热点常开.json` |
| 断网判定 | 只看有默认网关的网卡；`要全部判据网卡断开才算断网`=开 | **`只监视有线网卡`=开**；忽略列表额外加 `WLAN / 无线 / Wi-Fi`；全部断开才算断网 |
| 无线/热点 | 自动忽略 Wi-Fi Direct / 移动热点 / 虚拟网卡 | 同上（热点开关不影响断网判定） |
| 集中 DNS | 填教师机 IP；只锁判据网卡=开 | 同左（热点客户端不受影响） |
| 断网遮罩 | 开（随机壁纸 + 机位号 + 已断开时长） | 开 |
| 响鸣 | 60 秒后 3 次（可关） | 同左 |
| hosts 黑名单 | 关（有集中 DNS 就够）；hosts 只读保护=开 | 同左 |
| USB 存储 | 禁止 | 禁止（机器人等外设走非存储协议，如确需请改"允许"） |

**一体机机房必须先确认一件事**：这台机器的**无线是否会自动连校园 WiFi**？

- 若只用来开热点（不连校园网）→ 只监视有线**完全正确**；
- 若还会自动连校园网 → 建议在无线网卡上**取消该网络的"自动连接"**（热点功能不受影响），否则学生拔掉有线仍然能上网。

配好后每台机器核对：

```powershell
LabGuard.SelfTest.exe     # 看 [8] 网卡判据：会打印"本机实际判据网卡"和"全部网卡(忽略标记)"
```

## 4. 老师怎么用（日常）

| 场景 | 操作 |
|---|---|
| 想装软件 / 用 U 盘 / 用 cmd | 托盘小助手 → `系统功能（F）` → **暂停监控**（要密码） |
| 下课/维护结束 | 托盘 → 暂停监控 → 或直接重启电脑（默认开机自启） |
| 学生机被断网遮罩挡住 | 插回网线即自动消失；紧急时连续按 **5 次 Esc** → 输入密码解除 |
| 临时改策略 | 开始菜单 → **设置**（要密码）→ 改完保存，10 秒内生效 |
| 换机器补装 | 拷 `dist\` → `install-as-admin.cmd` → 导入配置（见下） |
| 统一改所有机器策略 | 在 1 台上改好 → 设置里【导出配置】→ 其他机器【导入配置】→ 保存 |

> **配置文件不能直接用记事本拷**：`%ProgramData%\LabGuard\config.json` 是用本机密钥加密的。
> 跨机器统一配置请走**导出/导入**（生成的 JSON 是明文，含口令散列，导完密码一致）。

## 5. 验收清单（每台 3 分钟）

1. `LabGuard.SelfTest.exe` → 全部通过（含 `[7] 设置项覆盖`、`[8] 网卡判据`）；
2. 托盘出现小助手图标；`--show-config` 输出与预期一致；
3. 设置能打开、能保存；托盘"暂停监控"要密码；
4. 拔网线演练（**学生测试机**上跑，脚本会自动恢复网卡）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File test-disconnect.ps1
   ```
   预期：20~30 秒后出现遮罩与提示；插回后 10 秒内自动消失；响鸣按设置次数；
5. 热点验证（一体机机房）：正常开/关 Windows 移动热点 → **不应**出现遮罩或"拔网线"提示；
6. 装完在硬盘保护/还原系统里保存进度。

## 6. 回退与救援（务必会）

| 情况 | 做法 |
|---|---|
| 想临时完全放开 | 托盘 → 退出程序（密码）→ 系统设置全部还原 |
| 忘记密码 | 用**管理员**运行 `uninstall.ps1`（会走 `LabGuard.Uninstall.exe --force`），或直接卸载程序：会还原所有改动 |
| 遮罩卡住 | 连续按 5 次 Esc → 密码；或 Ctrl+Alt+Del → 注销（注销后监控会停） |
| 程序被误删（杀毒软件） | 重新拷贝 `dist\` 到原安装目录（默认 `C:\Program Files\LabGuard`，可用 `--show-config` 或注册表 `HKLM\SOFTWARE\LabGuard` 的 `InstallDir` 查） |
| 彻底卸载 | 管理员运行 `uninstall.ps1`（还原 hosts / USB / 注册表策略 / 壁纸 / 服务 / 计划任务 / 快捷方式）→ 重启 |
| **最后的后路** | 进**安全模式（无网络）**——我们的服务/小助手在安全模式下**不加载**；然后运行 `cleanup-all.ps1`（纯 PowerShell，不需要安装目录里的任何文件）一键彻底卸载并还原。详见 [05-防破解与应急.md](05-防破解与应急.md) |

## 7. 风险与边界（部署前请知会老师）

### 6.1 口令保护到什么程度（重要，别误解）

| 入口 | 是否需要密码 |
|---|---|
| 托盘 → 暂停监控 / 退出程序 | **需要** |
| 设置程序（改任何策略） | **需要**（未设密码前不会启用监控） |
| 断网遮罩解除（连续 5 次 Esc） | **需要** |
| 卸载程序（`LabGuard.Uninstall.exe`） | **需要**；静默卸载必须带 `--password <密码>` |
| 改密码（`--init <新密码>`） | **需要旧密码** `--old <当前密码>`（防止免密重置） |
| 官方脚本 `uninstall.ps1` | 默认要密码（`-Password`）；只有老师显式加 `-ForceReset` 才跳过 |

**必须说清楚的边界**：以上都是"用户态"保护，能挡住**随手退出/随手卸载**，但**挡不住本地管理员**——
拿到管理员权限的人可以停服务、删目录、改注册表（Windows 上任何用户态程序都拦不住，也一样）。
所以：
1. **最有效的一招是让学生用标准账户**（机房需要用管理员权限装软件的课，用"老师临时给权限/密码暂停"的方式）；
2. 其次是**无盘还原/母盘派发**：学生删了、改了，重启就回来；
3. 最后是**交换机层限制**（只放行 53 到教师机）与电子教室离线名单。
4. 部署脚本、预设、`docs\`（里面有救援命令）**不要拷到学生机**——内置安装程序只会把"程序 + 壁纸"装进去；老师自己的那份留在 U 盘/教师机。

- 这是**管控类**软件：会限制下载、小游戏、任务管理器/注册表、U 盘、浏览器下载等。请先在教师会上说明用途，并写进机房管理规定。
- **不是防逃逸的终点**：学生仍可长按电源键、Ctrl+Alt+Del 注销、或 U 盘启动 PE。真正的兜底是交换机层限制（只放行 53 到教师机）+ 电子教室离线名单 + 机位实名 + 无盘还原。
- 集中 DNS（教师机 AdGuard）是**单点**：教师机不开机 → 学生机域名解析全失效（表现为"没网"），所以 AdGuard 必须开机自启，教师机也要当受管终端。
- 断网遮罩默认只"提示 + 遮罩 + 限次响鸣"，**不锁屏不关机**；要严格请到设置第 2 组打开对应开关（标红【危险】需谨慎）。
- 建议**先在一台机器上试运行一周**（含一次真实课堂），再整机房铺开。
