# 原版「学生机房管理助手 v13.03」原理分析

分析对象：随本仓库一起分析的**原版安装包与安装后的目录备份**（该目录不属于本仓库）。
本文只做**原理与结构分析**（黑盒+静态逆向），用于复刻一套等价的机房管控程序；不含对原版程序的破解、二次分发或授权绕过。

## 0. 结论速览

- 产品：**学生机房管理助手 v13.03**，厂商 `ZM软件工作室`（`www.jfglzs.com`），免费给学校信息老师用，靠**浏览器主页/导航站推广**变现。
- 形态：**纯本机策略管控程序**，没有教师端、没有 C/S 通信（官方"重要说明"明确"不需要安装教师机"）。所谓"教师控制"= 点击托盘图标 → 密码退出。
- 核心技术：`.NET Framework 4.5 + WinForms`（VB.NET 风格，`Microsoft.VisualBasic` 依赖明显）+ 一个 Windows 服务；保护壳是 **Eziriz IntelliLock（未注册版）**（字符串加密 + 控制流混淆 + 反篡改）。
- 管控手段：**注册表策略 / IFEO 映像劫持 / hosts 黑名单 / 服务启停 / 浏览器组策略 / 进程与窗口监控 / 文件系统监控 / 桌面与任务栏策略 / 注册表 ACL**。全部是"用户态、配置驱动"的运维手段，没有内核驱动。
- 安装特征：安装目录名由 MSI 属性拼出 `c:\f[PhysicalMemory][VirtualMemory]`（如 `c:\f1601615041`），随机化路径以增加学生定位/删除难度。

## 2. 保护壳（IntelliLock）

- 每个 exe 都是 .NET 4.5 程序集；`mscoree.dll` 引导，另有 `IntelliLock` 的加载器与反篡改代码（`VirtualProtect`/`OpenProcess`/`WriteProcessMemory`/`ReadProcessMemory`）。
- 明文字符串全部加密，调用点形如 `CheckRole(136)`；运行期由字符串表访问器还原（索引 = 参数/4）。控制流被扁平化成 `while+switch` 状态机，私有成员名被替换。
- 副作用：静态反编译能拿到**结构与方法签名**，但拿不到字符串；本文的字符串证据是通过"加载程序集 + 只调用字符串表访问器 + 屏蔽危险 API"的方式还原的（见 `_work/strdump/`）。
- 提示：`This assembly is protected by an unregistered version of "IntelliLock"!` 说明厂商用的是**未注册版**保护壳。

## 3. 配置与口令

- 策略配置集中在注册表 `HKLM\Software\jfglzs`，值名即功能开关：
  `zhuye`(主页) `usb_jianche`(U盘) `shadu_jianche`(杀毒软件) `cmd_jianche`(命令提示符) `win_jian`(Win键/任务栏右键) `games_jianche`(小游戏) `bianhao`(机器编号) `xiazai`(下载/新文件) `gaowei`(高危进程:任务管理器等) `zcb`(注册表编辑) `dzjs`(电子教室进程路径) `virtual`(虚拟桌面) `other`，取值 `on`/`off`。
- 口令相关值名做了混淆：`dtmm`、`czmm`、`bfdshgs`、`x2`、`ngfxd568bdh158`、`8bsdg45ybfdhg`（默认口令 `111111`）；`jfglzsn` 会**检测口令被改**并强制还原（"你修改了助手的密码！现在强制恢复密码！"）。
- 口令规则：6 位以上字母或数字，弱口令（如 `123456`）在设置时被拒绝。

## 4. 逐项管控原理

### 4.1 电子教室保护（jfglzsn.exe 主战场）

要保护的进程（配置 `dzjs`，并支持自动探测路径）：

| 电子教室 | 进程 | 常见路径 |
|---|---|---|
| 极域 | `StudentMain.exe` | `c:\...\StudentMain.exe` |
| 红蜘蛛 | `REDAgent.exe` | `C:\Program Files (x86)\3000soft\Red Spider\` |
| 锐捷云课堂 | `ClassMangerApp.exe` | `E:\...\ClassMangerApp.exe` |

针对学生常见脱控手法，逐条对应：

1. **拔网线/禁用网卡**：轮询 IP，出现 `169.254.`（APIPA）即判定断网 → 提示"你拔了网线或禁用了网络连接！请马上恢复网络，否则会全屏锁定！"（开机 2 分钟后才检测，避免误判）。
2. **改 IP 地址**：WMI 事件（`__InstanceCreationEvent` / `TargetInstance ISA 'Win32_Process'` 同族手法）比对新旧 IP → "你修改了IP地址！原地址为:" → 回写原 IP + 锁屏/重启提示。
3. **开防火墙"阻止所有传入连接"**：读 `SYSTEM\CurrentControlSet\Services\SharedAccess\Parameters\FirewallPolicy\{StandardProfile,PublicProfile}` 的 `EnableFirewall`，为 1 即"你启用了防火墙，危害电子教室的运行！现在助手强制关闭防火墙！" → 执行 `netsh advfirewall set allprofiles state off`。
4. **挂起/暂停电子教室进程**（任务管理器→资源监视器）：`NtSuspendProcess/NtResumeProcess` 检测线程挂起状态 → "电子教室程序被暂停！" → 强制 `NtResumeProcess`。
5. **cmd 杀进程**：注册表 IFEO 把 `taskkill.exe`、`ntsd.exe`、`tasklist.exe`、`route.exe` 的 `Debugger` 指向 `null`（映像劫持，程序一启动即失败）。
6. **极域万能密码/改频道**：监控 `SOFTWARE\TopDomain\e-Learning Class\Student` 的 `ChannelId`、`AutoLogin`（含 Wow6432Node）→ "你修改了极域电子教室的参数！请马上恢复，否则会锁屏！"；同时检查极域的 2 个关键服务是否存在/运行（"极域电子教室的2个重要服务不存在/停止！"）。
7. **改红蜘蛛/锐捷文件名或挪目录**：按路径+进程名持续检测，找不到 → 弹"电子教室进程未找到或本地连接IP地址错误！请重新启动电脑。"并可强制重启（`shutdown /s /f /t 0`）。
8. **虚拟桌面脱离控制**：`Explorer\Advanced\ShowTaskViewButton=0` 隐藏任务视图按钮 + 拦截 `Win` 键（`keybd_event`/`BlockInput`）+ 任务栏右键 `NoTrayContextMenu=1`。
9. **带网络的安全模式**：删除 `SYSTEM\CurrentControlSet\Control\SafeBoot\Network` 整棵子树，并 `bcdedit /set {bootmgr} displaybootmenu no`、删掉自制启动项 `{ee888888-…}`。
10. **360 流量防火墙/QQ管家断网、火绒**：进程名/窗口标题黑名单，见 4.3。

### 4.2 关机/加速类附加策略

为了"电子教室不死"和机房体验，顺带写入：`AutoEndTasks=1`、`HungAppTimeout`、`WaitToKillAppTimeout`、`Explorer\Serialize\StartupDelayInMSec=0`、`Tcpip6\Parameters\DisabledComponents`（关 IPv6）、`WindowsStore\RemoveWindowsStore=1`、`Search\SearchboxTaskbarMode`、`HideFileExt=1`、`NoFolderOptions=1`、`SHOWALL\CheckedValue=0`（隐藏系统/隐藏文件）、`DisableLockWorkstation=1`。

### 4.4 新文件/下载监控（przs.exe）

- 用 `FileSystemWatcher`（字符串 `tdfilefilter`/`tdnetfilter`）+ 定时轮询监控目录：`C:\Users\<每个用户>\Downloads`、`C:\`、`D:\`、`E:\`、`F:\`、`D:\ChromeCoreDownloads` 等。
- 高危扩展名：`.zip .rar .7z .arj .exe .com .msi .reg .bat .cmd .vbs .vbe .scr .dll .ps1 .pif` → 删除 + 提示"本电脑禁止下载安装软件，再次操作会锁屏！／刚刚删除文件：…"。
- 三档模式（注册表 `xiazai`）：**全部允许 / 仅 C++ 可生成新 exe（`.cpp .cp` 放行）/ 全部禁止**；另有针对"变相 exe、dll"（改扩展名）的检查，以及 `config.msi` 例外。
- 附带一条实用提示："mpython、考试软件、3d one 不能设为完全禁止"。

### 4.5 USB 存储设备（`usb_jianche`）

- 原理不是驱动过滤，而是**禁用 USB 存储驱动**：把 `SYSTEM\{CurrentControlSet,ControlSet001,ControlSet002,ControlSet003}\Services\usbstor` 的 `Start` 改为 4（Disabled）。
- 检测学生改回：注册表值监控 → "你修改注册表企图使用U盘！请重新启动电脑。"
- 退出/卸载时把 `Start` 还原（`huifu.reg` + `regedit /s`，配 `huifu.wav` 提示音）。

### 4.6 hosts 黑名单（域名封锁 + 隐藏 + 防删）

- 头部注释"由机房管理助手自动生成"；正文把域名写成 `127.0.0.1 <域名>`，来源两处：
  - 本地清单 `hmd_local.txt`（实测：lanzou*/蓝奏、123pan、百度网盘、阿里云盘、夸克、迅雷、CSDN 下载、poki 小游戏站、破解站 `fuck-jfglzs.lzh173.chat` 等 80+ 条）；
  - 网络清单 `http://<服务器>/hmd_net.txt`（设置程序联网下载，失败时提示"网络不通!请先恢复网络，需要下载黑名单等。"）。
- 更新后 `ipconfig /flushdns`；`hosts` 文件设 Hidden，并配合"隐藏受保护的操作系统文件=关、不显示隐藏文件、不显示扩展名"使其看不出改动。
- 守护：`przs` 轮询 hosts 存在性与内容（备份 `hosts-bak`）→ "hosts文件被删除！现在恢复。"；多次被删 → "hosts文件多次被删除或备份文件不存在！"。
- 防绕过：`route.exe` 用 IFEO 禁用；`route add <域名> mask 255.255.255.255 0.0.0.0 metric 1` 这类"直连绕 DNS"手法被照顾到。

### 4.7 浏览器管控（组策略 + 快捷方式劫持）

只写**注册表策略**，不动浏览器本体：

| 浏览器 | 键 | 值 |
|---|---|---|
| Chrome | `SOFTWARE\Policies\Google\Chrome` | `DownloadRestrictions=3`(禁止下载)、`AllowDinosaurEasterEgg=0`(关小恐龙) |
| Edge | `SOFTWARE\Policies\Microsoft\Edge` | `DownloadRestrictions=3`、`AllowSurfGame=0`(关冲浪游戏)、`DeveloperToolsAvailability`、`SaveAs` |
| Firefox | `SOFTWARE\Policies\Mozilla\Firefox` | `DisableDownloads`、`BlockAboutDownloads` |
| IE | `…\Internet Settings\Zones\3` | `1803`(=禁用文件下载)、`2200`；另有 `NoBrowserSaveAs` |

快捷方式劫持（数据源：`zy\` 9 个假浏览器 + `百度搜索&网址导航.url`）：扫描桌面、`C:\Users\Public\Desktop`、快速启动、任务栏固定区、收藏夹链接、IE LinksBar，凡是目标指向 chrome/msedge/firefox/360/2345/qq/极速/双核 的快捷方式，全部改用 `WScript.Shell.CreateShortcut` 把 `TargetPath` 改成 `zy\<对应>.exe`。

### 4.8 桌面壁纸与机器编号

- 6 张 1920×1080 壁纸，写入 `Control Panel\Desktop` 的 `Wallpaper`/`WallpaperStyle`；
- 机器编号取 `COMPUTERNAME` **后 6 位**，画在**右上角**（przs 的 `bianhao` 窗体 + "黑体/宋体"、"stu30" 字号资源、"由机房管理助手自动生成"）；卸载时还原 `C:\Windows\Web\Wallpaper\Windows\img0.jpg`。

### 4.9 自我保护与"锁定"

- `zmserv` 服务：`sc create zmserv binPath=… start= auto` + **`sc failure zmserv actions= "reboot/60000/reboot/60000/reboot/60000" reset= 300`**（服务异常退出 60 秒后强制重启电脑）。
- 服务本身会 `net start/stop zmserv`、找到 `C:\windows\jf\jfglzsn.exe` 拉起/守护，并对违规场景执行 `shutdown /s /f /t 0`。
- 注册表 ACL 加固：`regini.exe regqx.ini`，内容
  `HKLM\SOFTWARE [1 7 17]`（1=Administrators 完全控制、7=SYSTEM 完全控制、17=Users 只读）、
  `HKLM\SOFTWARE\Microsoft\Internet Explorer\MAIN`、`HKCU\…\Internet Explorer\Main`、
  `HKLM\SYSTEM\CurrentControlSet\Control\SafeBoot\Network`；解除用 `regqxoff.ini`。
- 文件完整性：每个程序旁有 `.dat` 状态文件（`jfglzsn.dat`/`przs.dat`/`zmserv.dat`）；被删/被多次终止会提示"进程被多次终止或文件会被杀毒软件（如 win10 自带的 defender）清除！"。
- 锁屏：全屏窗口 + `BlockInput`（键鼠失效，只留 Ctrl+Alt+Del），文案"请马上恢复网络，否则会全屏锁定！"；启动时若关键文件缺失 → 直接进入"蓝屏锁定"（模拟蓝屏画面 + 锁输入）。

### 4.10 退出与卸载

- 托盘 `about.exe` → 系统功能(F)：设置／启动程序／退出程序（**要密码**，"注：用密码退出后可使用U盘、下载文件，停止监控"，退出按钮"退出(需10秒)"）；
  —— 退出动作会逐项还原：USB 驱动 Start、`DisableCMD`、IE/Edge/Chrome/Firefox 下载策略、`usbstor`、`net stop zmserv`。
- `uninstall.exe`：密码 → 还原壁纸、hosts/hosts-bak、注册表策略、IFEO、`bcdedit /set {bootmgr} displaybootmenu yes`、USB、虚拟桌面、`sc delete zmserv`、`net stop zmserv`、删文件，最后 `shutdown /r /f /t 0`。

## 5. 一句话总结原理

> 它不是一个"驱动级"管控软件，而是把 Windows 自带的**运维开关**（组策略/注册表策略、IFEO 映像劫持、服务控制、hosts、Explorer 策略、注册表 ACL、进程与文件监控）按机房的场景编排成一套**自愈式策略引擎**：任何被学生改动的关键开关，都会被以秒级/分钟级轮询恢复；恢复不了就提示、锁屏或强制关机。它的"强"来自覆盖面全 + 自愈 + 多进程互相守护，而不是技术深度。
